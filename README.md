# Decoder from scratch for sonnet generation

This academic project aimed to implement a decoder from scratch at the character-level, that aimed to generate sonnets (or more specifically
to analyse the emergence of capabilities). 

Results obtained shown that even with less than 5Mb of french sonnets, words appeared, rhymes seemed to emerge but the most 
important point was that the whole structure was already there with well formed words (with no semantics however) and french's sonnet structure.
